# Sources, licenses and publication gate

Review actual applicable terms before redistribution or public hosting. This file records sources and open questions, not legal advice or a grant of permission.

- **Wealth Algorithm**: source snapshot `1a192eeb2a182f1a32a071d1dd51163936218e2a`, [Wealth Algorithm](https://github.com/DuncanDuMond/Wealth-Algorithm). The inspected root has no explicit license. Author permission/license must be resolved before distribution. The upstream README, source comments and data are retained under `vendor/wealth_algorithm`.
- **Swiss Ephemeris / pyswisseph**: [aloistr/swisseph](https://github.com/aloistr/swisseph) and [astrorigin/pyswisseph](https://github.com/astrorigin/pyswisseph). The library's dual AGPL/professional route and the Python wrapper's own license must both be checked for the chosen distribution/deployment. A professional Swiss license does not by itself establish rights to every wrapper or asset. The original `sefstars.txt` is retained; no new proprietary ephemeris data is included.
- **Stellarium desktop**: [Stellarium](https://github.com/Stellarium/stellarium). GPL-2.0-or-later source; not bundled here. This application generates user-run scripts or communicates with a separately installed, explicitly enabled local viewer.
- **Stellarium Web Engine**: [Stellarium Web Engine](https://github.com/Stellarium/stellarium-web-engine). AGPL-3.0 source; not bundled. Embedding the engine and shipping sky datasets requires separate code/data license review and build validation.
- **Leaflet 1.9.4**: [Leaflet 1.9.4](https://github.com/Leaflet/Leaflet/tree/v1.9.4). BSD-2-Clause; vendored assets and its license are in `web/vendor/leaflet`. World boundaries are copied from the upstream Wealth Algorithm dataset; confirm the dataset's original provenance/attribution before publication.
- **GeoNames / geonamescache 3.0.2**: [GeoNames](https://www.geonames.org/) and [geonamescache](https://github.com/yaph/geonamescache). The Python package is MIT; geographic data is made available under GeoNames' Creative Commons attribution terms. The app uses a local city subset and preserves source information. No query is sent to GeoNames. Country borders/names in data are not statements of political endorsement.
- **FastAPI, Pydantic, HTTPX, Uvicorn, pytest, Ruff, Playwright, MCP Python SDK**: official projects supply the web boundary, validation, transport and verification. Installed packages retain their license metadata. Review the locked dependency set for public distribution.

The new application has no arbitrarily assigned open-source license. Choose the application's public/open-source or private/commercial route before public distribution. A private source repository does not resolve these licensing questions or constitute a public deployment.
